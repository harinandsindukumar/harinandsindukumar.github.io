# Harinand Sindukumar | Portfolio Website

Welcome to my personal portfolio website showcasing my projects, skills, and journey as a developer.

## 🚀 Live Site

Visit: [https://iths.online](https://iths.online)

## 📦 Features

- **Modern UI/UX** - Built with React, Tailwind CSS, and Framer Motion
- **Responsive Design** - Optimized for all devices
- **Interactive Animations** - Smooth animations using GSAP and Framer Motion
- **SEO Optimized** - Complete meta tags and structured data
- **Masonry Gallery** - Dynamic photo gallery showcasing projects
- **Spotlight Cards** - Interactive mouse-tracking spotlight effect on cards
- **Decrypted Text Animation** - Hacker-style text reveal effects

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion, GSAP
- **Icons**: Lucide React, React Icons
- **Deployment**: GitHub Pages

## 🏃‍♂️ Running Locally

```bash
# Clone the repository
git clone https://github.com/harinandsindukumar/harinandsindukumar.github.io.git

# Install dependencies
npm install

# Start development server
npm run dev
```

## 📦 Build & Deploy

```bash
# Build for production
npm run build

# Deploy to GitHub Pages
npm run deploy
```
